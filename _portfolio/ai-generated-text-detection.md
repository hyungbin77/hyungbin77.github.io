**역할** — 공동 제1저자 (응용통계연구 39(3), 235–255, 2026.06 게재)
**기술** — Python, PyTorch, NLTK, gensim, LDA, Llama-3.1-8B, LLM API

## 진행 내용

- **벤치마크 말뭉치 자체 구축** — 총 14,833문서 / 3,880,637토큰.
  Quora 질의응답 크롤링(인간 2,833) + GPT-4o · Gemini 2.0 Flash · Claude 3.7 Sonnet · DeepSeek 각 3,000
  - 질문 100개 × 모형별 30회 반복 생성, 5개 주제로 층화
  - 프롬프트 4유형을 검토해 편향을 유발하는 유형을 제외하고 단일 공통 프롬프트 설계
- **특징 설계** — 문체 지표(고유 단어 수, 개인 대명사 비율, 어휘 밀도, Flesch-Kincaid)
  + LDA 주제 분포(coherence score로 주제 수 5개 선정) + Llama-3.1-8B 혼란도
- **분류기 구축** — 은닉층 4개 DNN(256-128-64-32)으로 이진 분류와 원천 5범주 분류를 동시 수행
- **성능** — 이진 분류 정확도 0.9778 / F1 0.9864, 다중 분류 정확도 0.8598 / Macro F1 0.8607
- **기여** — 혼란도 단독 대비 다중 분류 오분류율 0.3866 감소
